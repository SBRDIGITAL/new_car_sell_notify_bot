# Тесты для New Car Sell Notify Bot

Директория содержит тестовые скрипты для проверки работы различных компонентов бота.

## Предварительные требования

Перед запуском тестов убедитесь, что:

1. ✅ Виртуальное окружение активировано
2. ✅ Все зависимости установлены (`pip install -r requirements.txt`)
3. ✅ API сервис уведомлений запущен (`http://localhost:8000`)
4. ✅ Настроен файл `.env` с корректными параметрами:
   - `BOT_TOKEN` - токен Telegram бота
   - `ADMINS_TG_IDS` - ID администраторов через запятую
   - `NOTIFY_API_HOST` - хост API (по умолчанию `localhost`)
   - `NOTIFY_API_PORT` - порт API (по умолчанию `8000`)

## Структура тестов

### 1. `test_add_notifies.py` - Добавление уведомлений

**Назначение:** Добавляет 3 тестовых уведомления о продаже автомобилей в API.

**Запуск:**
```bash
python -m tests.test_add_notifies
```

**Что проверяет:**
- Подключение к API
- Добавление уведомлений через POST запросы
- Валидацию данных (URL, телефон, аналитика)

**Ожидаемый результат:**
```
✅ Успешно добавлено: 3
❌ Ошибок: 0
```

---

### 2. `test_poller.py` - Работа поллера

**Назначение:** Проверяет получение уведомлений поллером и отправку их администраторам.

**Запуск:**
```bash
python -m tests.test_poller
```

**Что проверяет:**
- Создание экземпляра бота
- Получение уведомлений через поллер
- Отправку уведомлений администраторам в Telegram
- Работу сервиса `AdminNotifyService`

**Ожидаемый результат:**
- Уведомления получены из API
- Сообщения отправлены в Telegram администраторам
- Логи показывают успешную отправку

**Примечание:** Для работы требуется, чтобы в API были добавлены уведомления (например, через `test_add_notifies.py`).

---

### 3. `test_direct_api.py` - Прямой тест API

**Назначение:** Прямое тестирование API без использования клиента приложения.

**Запуск:**
```bash
python -m tests.test_direct_api
```

**Что проверяет:**
- POST запрос: добавление уведомления
- GET запрос: получение уведомлений
- Автоматическую очистку после GET запроса

**Ожидаемый результат:**
```
ШАГ 1: Статус 200 - уведомление добавлено
ШАГ 2: Статус 200 - получено 1 уведомление
ШАГ 3: Статус 200 - список пуст (очищен)
```

---

### 4. `test_combined.py` - Комплексный тест

**Назначение:** Полный цикл: добавление → получение → отправка администраторам.

**Запуск:**
```bash
python -m tests.test_combined
```

**Что проверяет:**
- Добавление 3 уведомлений в API
- Получение их через поллер
- Отправку администраторам через Telegram бота
- Полную интеграцию всех компонентов

**Ожидаемый результат:**
- Все уведомления добавлены
- Все уведомления получены поллером
- Все уведомления отправлены администраторам
- Проверьте Telegram для подтверждения получения

---

Запустить все тесты последовательно можно командой:


## Устранение неполадок

### Ошибка: `ModuleNotFoundError: No module named 'app'`

**Решение:** Запускайте тесты из корня проекта как модули:
```bash
cd c:/Users/user/Documents/dev/sbr_projects/new_car_sell_notify_bot
python -m tests.test_add_notifies
```

### Ошибка: Connection refused

**Причина:** API сервис не запущен.

**Решение:** Запустите API сервис уведомлений на `http://localhost:8000`.

### Уведомления не приходят в Telegram

**Проверьте:**
1. Корректность `BOT_TOKEN` в `.env`
2. Корректность `ADMINS_TG_IDS` в `.env`
3. Бот добавлен в контакты пользователя
4. У бота есть права на отправку сообщений

### API возвращает пустой список

**Причина:** Уведомления были уже получены предыдущим GET запросом (список автоматически очищается).

**Решение:** Добавьте новые уведомления через `test_add_notifies.py`.

- Максимум 100 уведомлений за один GET запрос
